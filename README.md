Smart Library Management System 
----
This project was made using python and using some python modules like json, datetime and tkinter.

The Console version 
----
The console version runs in the terminal and it has features like adding, removing, lending, accepting books and it also registers users
It has also Admin privileged options like adding adn removing a book requires the admin password.
It also checks for overdues.

The Gui app version 
----
The GUI version also runs on the same logic as the console version.
It is built using the python library tkinter.
It has different windows for user and Admin pages.
For the users they have options to singup or login using their id given and password
